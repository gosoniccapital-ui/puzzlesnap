# Taste Redesign Skill (Anti-Slop Luxury Overhaul)

This skill specializes in taking existing functional code and performing an **aesthetic and atmospheric elevation** without breaking existing routes, logic, or data flow.

## The 3 Dials Architecture
- **`DESIGN_VARIANCE: 8`** (1 = Rigid Grid, 10 = High-Fashion Editorial Asymmetry)
- **`MOTION_INTENSITY: 6`** (1 = Static, 10 = Fluid Micro-animations, smooth transitions, tactile hover states)
- **`VISUAL_DENSITY: 4`** (1 = Airy Art Gallery, 10 = Packed Data Cockpit)

## Redesign Transformation Steps for Luxury Fashion:
1. **Atmospheric Canvas:** Dark Haute Couture backdrop with layered radial gradients, subtle noise/grain texture, and hairline champagne-gold dividers.
2. **Typography Pairing:** High-contrast editorial display font for titles (`Cinzel`, `Playfair Display`, `Cormorant`) paired with technical clean sans-serif for UI labels and numeric values.
3. **Elevated Hero & Search Experience:** 
   - Floating omni-search capsule with metallic hairline border, smooth backdrop blur, glowing focus ring, and tactile camera button.
   - Quick search chips styled with luxury tag aesthetics (champagne borders, subtle hover glows).
4. **Curated Product Cards:**
   - Image presentation with aspect-ratio luxury framing (3:4 or 4:5 fashion portrait ratio).
   - Glassmorphic price tags with currency highlights.
   - Distinct platform attribution badges (Amazon US Prime, Rakuten Tokyo, CunCute Official).
   - 1-click tactile bookmarking with animated heart fill.
5. **Fluid Motion & Micro-interactions:**
   - Smooth `transition-all duration-300 ease-out` on card hovers.
   - `hover:-translate-y-1 hover:shadow-2xl` with warm amber light dispersion.
