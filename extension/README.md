# 👗 Cun Style Advisor - Google Chrome Extension (Manifest V3)

> Tiện ích mở rộng thông minh giúp bạn nhận gợi ý phối đồ thời trang chuẩn gu ngay khi lướt web trên Shopee, TikTok Shop, Pinterest, Instagram, Zara, Taobao...

---

## 🚀 Hướng Dẫn Cài Đặt Vào Google Chrome (30 Giây)

1. Mở trình duyệt **Google Chrome** hoặc **Cốc Cốc** / **Microsoft Edge**.
2. Truy cập vào trang quản lý extension bằng cách gõ vào thanh địa chỉ:
   ```
   chrome://extensions
   ```
3. Bật công tắc **Developer mode** (Chế độ dành cho nhà phát triển) ở góc trên bên phải màn hình.
4. Bấm nút **Load unpacked** (Tải tiện ích đã giải nén) ở góc trên bên trái.
5. Chọn thư mục sau trong dự án:
   ```
   g:\AWE\puzzle-tung\extension\cun-style-advisor
   ```
6. Bấm chọn **Select Folder**. Tiện ích **Cun Style Advisor** sẽ xuất hiện ngay lập tức!
7. *(Khuyên dùng)* Bấm vào biểu tượng mảnh ghép (Extensions) trên thanh công cụ Chrome và **Ghim (Pin)** icon chữ **C** màu hồng của Cun Style Advisor để sử dụng tiện lợi nhất.

## 🎯 Cách Sử Dụng Khi Lướt Web

### Cách 1: Click chuột phải vào bất kỳ hình ảnh nào trên web
- Khi đang lướt Shopee, TikTok Shop, Pinterest, Instagram, Facebook...
- Thấy bất kỳ bức ảnh người mẫu hoặc trang phục nào đẹp, **click chuột phải vào ảnh** -> Chọn **"👗 Tư vấn phối đồ với Cun Style Advisor"**.
- Bấm vào icon Cun Style Advisor trên thanh trình duyệt -> Ảnh đó sẽ được tự động nhận diện và gợi ý ngay set đồ phối hợp + sản phẩm liên quan!

### Cách 2: Mở Popup trực tiếp
- Bấm vào icon **Cun Style Advisor** trên thanh trình duyệt.
- Tải ảnh lên từ máy tính hoặc chọn Dịp sử dụng (Đi chơi, Đi làm, Hẹn hò, Party, Du lịch), Phong cách và Ngân sách.
- Bấm **"Phân Tích & Gợi Ý Sản Phẩm"** để nhận lời khuyên stylist và link mua hàng affiliate.
